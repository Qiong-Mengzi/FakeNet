```python
class Pendant:
    def __init__(self):
        self.rect: Rect = Rect()

        self._cache: Surface | None = None

    def render_only(self) -> Surface:
        """重新绘制Pendant并缓存"""
        self._cache = Surface(self.rect.size)
        return self._cache

    def render(self, screen: Surface) -> Surface:
        if not self._cache:
            self._cache = self.render_only()
        screen.blit(self._cache, self.rect.topleft)
        return screen
```

问题来了，`Surface` 是支持 `blits` 批量绘制的
