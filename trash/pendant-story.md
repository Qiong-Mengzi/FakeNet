这份UI的结构

端出一个小小的栗子

按钮 `Button`

- 正常状态 / `normal`
- 鼠标悬停 / `hover`
- 按下 / `press`
- 禁用 / `disable`

这样的话就会产生一个图

```
begin(/) -> [normal]
on_hover(normal) -> [hover]
on_press(normal) -> [press]
on_release(press) -> [normal]
on_nonhover(hover) -> [normal]
```

每一个动作将状态转移到另一个状态上

通常来说，这样子唯一不知道怎么变化的，只有文字了

让「我们」再试试，至少能...抓住些什么...
